# Last.fm Stats

Personal Last.fm listening statistics and history.

🌐 **[View the live stats](https://thugg59.github.io/lastfm-stats/)**

## About

This repository contains my personal Last.fm data pipeline and the public-facing statistics generated from my listening history.

The site includes:

* Listening overview
* Top artists
* Top tracks
* Yearly listening statistics
* Monthly listening statistics
* Listening patterns by hour

The data is automatically updated using GitHub Actions.

## Tech Stack

* Python
* PostgreSQL
* Last.fm API
* GitHub Actions
* GitHub Pages
