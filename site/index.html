About the Data

This dashboard is powered by an automated data engineering pipeline that extracts listening data from the Last.fm API, transforms and validates the data, and loads it into PostgreSQL.

The pipeline runs automatically using GitHub Actions. PostgreSQL is hosted on Google Cloud and is accessed securely through an Identity-Aware Proxy tunnel.
